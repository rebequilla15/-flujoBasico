# Práctica 2 - Conceptos Báscos de Base De Datos

# 1-¿Qué es una Base De Datos Relacional?
Es un sistema que guarda datos en tablas con filas y columnas.
Así es más fácil relacionar información y hacer consultas.
Se usa mucho en apps y sitios web.
Es como un gran archivero digital.

# 2-¿Qué es una Tabla en el contexto Base De Datos Relacionales?
Una tabla es como una hoja de cálculo con columnas y filas.
Cada tabla guarda info sobre algo específico, como usuarios o productos.
Tiene un nombre único y una estructura definida.
Es la base de la base de datos.

# 3-¿Qué es una relación en el contexto de Base De Datos Relacionales?
Es cuando conectas dos tablas para obtener info de ambas.
Se hace mediante claves, como IDs.
Así puedes saber qué pedidos hizo un cliente.
Es como hacer un enlace entre dos cosas.

# 4-¿Qué representa una columna en el contexto de Base De Datos Relacionales?
Una columna es un campo o característica de la tabla.
Cada columna tiene un tipo de dato, como texto o número.
Es como una etiqueta para la info que guarda.
Define qué tipo de info se guarda en la tabla.

# 5-¿Qué representa un renglón en el contexto de Base De Datos Relacionales?
Un renglón es un registro o entrada en la tabla.
Cada renglón tiene valores para cada columna.
Es como una ficha de info sobre algo específico.
Representa un objeto o entidad en la tabla.

# 6-¿Qué es un motor de base de datos relacional?
Es el software que maneja la base de datos, como MySQL.
Se encarga de procesar consultas y guardar datos.
Es como el cerebro de la base de datos.
Gestiona la seguridad y la integridad de los datos.

# 7-¿Cuáles son los motores de bases de datos relacionales más populares?
Los más conocidos son MySQL, PostgreSQL y Microsoft SQL Server.
Cada uno tiene sus ventajas y desventajas.
Se elige según las necesidades del proyecto.
Hay opciones de código abierto y comerciales.

# 8-¿Cuál es el motor de base de datos ligero que no necesita un servidor?
Es SQLite, es como una base de datos mini.
Se integra en la app y no necesita configuración.
Es ideal para apps pequeñas o móviles.
Es muy ligero y fácil de usar.

# 9-¿Qué significa SQL en el contexto de base datos relacionales?
SQL significa "Structured Query Language".
Es el lenguaje para consultar y manejar bases de datos.
Se usa para hacer consultas, insertar datos, etc.
Es el lenguaje estándar para bases de datos.

# 10-¿Cuáles son los elementos de un sistema de información basado en base de datos relacionales?
Son la base de datos, el motor y el lenguaje SQL.
También incluye apps y usuarios que interactúan con la base.
Es como un equipo que trabaja junto.
Gestionan la info y la hacen accesible.
